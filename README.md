# Il Tarlo del Risparmio — template finale

## File da caricare su GitHub

- bot.py
- requirements.txt
- template.png

## Configurazione

Apri `bot.py` e inserisci il token:

TELEGRAM_TOKEN = "TOKEN_BOTFATHER"

## Render

Build command:

pip install -r requirements.txt

Start command:

python bot.py

## Zone gestite dal codice

- Immagine prodotto: riquadro bianco grande a sinistra
- Titolo: riquadro verde vuoto in alto a destra
- Sottotitolo: striscia verde vuota sotto il titolo
- Prezzo attuale: box bianco dentro il riquadro arancione
- Prezzo precedente: box bianco inferiore

Le tre righe:
- Sconto imperdibile
- Qualità garantita
- Spedizione veloce

non vengono mai modificate.
