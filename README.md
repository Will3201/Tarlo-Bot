# Il Tarlo del Risparmio — senza variabili Render

1. Apri `config.py`.
2. Incolla il token BotFather al posto di `INCOLLA_QUI_IL_TOKEN_BOTFATHER`.
3. Imposta il canale e una password in `ADMIN_SECRET`.
4. Salva e carica tutti i file su un repository GitHub PRIVATO.
5. Collega il repository a Render e fai il deploy.

Test:
- `https://TUO-SERVIZIO.onrender.com/health`
- `https://TUO-SERVIZIO.onrender.com/publish?secret=LA-TUA-PASSWORD`

ATTENZIONE:
Non usare un repository pubblico: il token Telegram sarebbe visibile a chiunque.
