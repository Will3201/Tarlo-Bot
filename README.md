# Avvio rapido

1. Apri bot.py.
2. Incolla il token nella riga TELEGRAM_TOKEN.
3. Controlla CANALE_CHAT_ID.
4. Carica bot.py, requirements.txt e template.png su GitHub.
5. Su Render usa:

Build command:
pip install -r requirements.txt

Start command:
python bot.py

Il bot pubblica immediatamente al riavvio e poi ogni 30 minuti.

Il bot deve essere amministratore del canale con permesso di pubblicare.
