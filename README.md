# Contenuti giornalieri del Tarlo

Questo ramo conserva solo creatività pubbliche e il registro delle pubblicazioni TikTok, per sopravvivere ai riavvii di Render Free. Non è un ramo di deploy.

media/YYYY-MM-DD.png: foto verificata.
records/YYYY-MM-DD.json: ID del contenuto, hash immagine, stato del tentativo e ID/URL Metricool se disponibili. Nessun token, dato di accesso o sessione.

Prima di inviare: leggere il registro, il planner e i post TikTok pubblicati. Se esiste un tentativo con esito incerto, non ripetere automaticamente l'invio. Scrivere lo stato attempted prima della chiamata Metricool e scheduled dopo una risposta positiva.
